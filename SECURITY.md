# Security Policy

## Supported Versions

This package is currently pre-1.0. Only the latest release receives security fixes.

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |
| < 0.1   | ❌        |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please report vulnerabilities privately:

1. Use GitHub's **"Report a vulnerability"** feature (Security tab → Advisories → New advisory), **or**
2. Email the maintainer directly.

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce (proof of concept if possible).
- Affected versions.

You should receive an initial response within **72 hours**. Please do not disclose the issue publicly until a fix has been released.

## Scope

This policy covers the `fengz/laravel-lang-zh-cn` source code. As a language-file package, it contains no credentials, secrets, or runtime data flows. It does **not** cover:

- Issues arising from edits you make to published language files in your own application.
- Vulnerabilities in Laravel, PHP, or third-party dependencies — report those upstream.
